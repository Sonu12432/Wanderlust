# Wanderlust 🌍
**A Full-Stack Destination & Hotel Booking Application**

Wanderlust is a web-based platform designed for travelers to explore iconic destinations and book accommodations. Built with the **MVC architecture**, it allows users to browse listings, view detailed place descriptions, and manage their bookings through a seamless interface.

---

## 🏗️ Architecture & Features

This project follows the **Model-View-Controller (MVC)** design pattern to ensure a clean separation of concerns and maintainable code.

### Core Functionalities (CRUD):
- **Create:** Users can list new destinations or hotels with images and descriptions.
- **Read:** Browse a gallery of available places and view specific details for each listing.
- **Update:** Edit existing listings to keep prices, descriptions, or availability current.
- **Delete:** Remove listings from the platform.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Bootstrap/Tailwind), JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (NoSQL)
- **View Engine:** EJS (Embedded JavaScript) or React
- **Authentication:** Passport.js / JWT
